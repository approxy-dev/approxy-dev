## What I've built

### 📱 [Pausen — Android Bedtime App & Scroll Pause App](https://github.com/approxy-dev/Pausen-App)
A quiet native Android bedtime app and scroll pause app (formerly **SleepGuardian APK**). Download the official **Pausen APK** directly — no ads, no trackers, and no internet permission.

- Scheduled wind-down, bedtime curfews, and a warm screen tint
- Breathing pauses with a 24-hour commitment to help interrupt long scrolling sessions
- Fully on-device: no internet permission, no accounts, no ads, and no analytics

📥 [Download Pausen APK (v1.10.2)](https://github.com/approxy-dev/Pausen-App/releases/download/v1.10.2/Pausen-1.10.2.apk) · 💻 [Pausen Repository & Showcase](https://github.com/approxy-dev/Pausen-App)

### 🌙 [SleepGuardian](https://sleepguardian.vercel.app)
A bedtime commitment device for Windows. At your curfew, your PC shuts down. When it turns back on, it stays locked until your wake time. No snooze button.

- Enforced by a resilient background Windows service (SYSTEM)
- Fully offline and local (SQLite). Zero telemetry, zero cloud calls
- Streaks, calendar heatmap, and CSV/JSON export

🌐 [Official Website](https://sleepguardian.vercel.app) · 💻 [Repository](https://github.com/approxy-dev/sleep-guardian)

### 💻 [PCReady](https://pcready.vercel.app)
Rebuild your Windows software environment after a fresh install.

- 336 curated apps across 23 categories, with 5 ready-made setup profiles
- Automated package installation through Microsoft WinGet
- Single portable binary — no installer, no extra runtime needed

🌐 [Official Website](https://pcready.vercel.app) · 💻 [Repository](https://github.com/approxy-dev/PCReady)
